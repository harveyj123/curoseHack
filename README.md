# CuroseHack

Our project for the Crusoe x Cerebral Valley Recursive Agents Hackathon, built on Crusoe Managed Inference (`https://api.inference.crusoecloud.com/v1`). See [docs/crusoe-skill.md](docs/crusoe-skill.md) for models, rate limits and API details.

## Setup

1. Copy `.env.example` to `.env`.
2. Fill in `CRUSOE_ACCESS_KEY` and `CRUSOE_SECRET_KEY` with your Crusoe Cloud API keys.

Never commit `.env`; it is ignored by git.
